# Как делать новый ролик

## Процесс

1. **Одна мысль.** Сформулируй вывод одной строкой: «Буфер не убирает ожидание, он его откладывает». Это последняя фраза и место фокуса.
2. **Актёры.** 3–6 сущностей, роль у каждой. Если нужна седьмая, тема делится на два ролика.
3. **Сценарий по секундам.** 4–6 фраз по 3–4 секунды. На каждую фразу одно физическое событие: значение полетело, легло, упёрлось, ушло.
4. **JSON.** Сущности, события, код, субтитры (см. «Формат сцены»). Удобнее всего попросить Claude, промпт ниже.
5. **Кадры.** `python -m maket stills scene.json out 2 6 10 14` — посмотреть самые загруженные моменты: не налезают ли подписи, читается ли код.
6. **Рендер.** `python -m maket render scene.json out.mp4`.
7. **Голос.** Записать по субтитрам, подогнать тайминги `captions` и `events` под реальную речь, перерендерить.
8. **Монтаж.** Голос + музыка поверх, громкость эффектов не трогать.

## Промпт для Claude

```
Сделай сцену для движка maket (стиль «Макет») по теме: <тема>.
Вывод ролика одной строкой: <вывод>.
Правила: 15–25 секунд, 3–6 сущностей, роли producer / consumer / buffer /
storage / external, раскладка по колонкам −2.5 / 0 / 2.5 и рядам через 4–5
по глубине, поток сверху вниз. Одно красное событие на сцену, фокус на
финальной фразе. Код — валидный Go, до 7 строк по 38 символов. Субтитры —
короткие фразы, активный залог, первая фраза уже действие.
Отдай только JSON по формату сцены maket.
```

## Чек-лист перед рендером

- [ ] Первое действие не раньше 1.0 с: сцена успела вырасти.
- [ ] Каждое значение летит, когда о нём говорят, не раньше.
- [ ] Красный ровно один раз и с `until`.
- [ ] Финальная фраза и `focus` совпадают.
- [ ] Подписи не налезают (смотри кадры).
- [ ] Числа в кадре реальные: замер, документация или явное «~».
