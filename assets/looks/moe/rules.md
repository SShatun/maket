# Моэ

Третий режим сцены: аниме-чиби. Каждый объект становится персонажем со своим характером, настроение кадра несёт фон, а эмоции показываются знаками из манги. Превью в движении лежит в группе Previews (`moe-live.gif`), пример ролика — в Examples (`session-chan.mp4`).

## Когда Моэ
| Макет | Пиксели | Моэ |
|---|---|---|
| устройство: где лежит и сколько | поведение: кто ждёт, падает, спорит | отношение: кто кого ждёт и что при этом чувствует |
| буфер, кэш, шардирование | дедлок, ребаланс, retry storm | сессия ждёт разрешения, кэш отдаёт мгновенно, вахтёр не пускает |

Проверка: если фразу хочется сказать от лица объекта («Я НЕ упала, бака!»), выбирай Моэ. Один ролик — один режим. Технические детали в Моэ показываются не кубиками, а голограммами в кадре (см. ниже).

## Каст
| Образ | Кто | Характер | Состояния |
|---|---|---|---|
| person | человек с телефоном (простой чиби, без моэ) | зритель в кадре | idle, wait, surprised, happy |
| session | Сессия-тян: кошкодевочка, хвостики, бубенчик | цундере | idle, type (голо-клавиатура), wait (руки скрещены, часы, ふんっ), sleep; только у неё ещё tsun, baka, dere, happy, love, shock, sad, smug |
| dialog | девочка-зайка с табличками Yes / No | нетерпеливая | idle, impatient (Yes светится, はやく!), closed (ぽん, исчезает) |
| service | горничная со счётами | старательная | idle, count (+1), wait, skip (пожимает плечами), bad (глаза крестиками, дым) |
| queue | девочка в худи у конвейера | кудере | run, stop (спит), full (коробки валятся, あわわ) |
| branch | дриада с ростком в горшке | восторженная | idle, grow, pushed (улетает, ぴゅーん) |
| db | библиотекарь в очках у картотеки | аккуратная | idle, give (выдвигает ящик, отдаёт карточку), empty (паутина, пыль) |
| cache | лисичка с рюкзаком | дередере | idle, give (достаёт ответ, はい!), miss (карманы вывернуты) |
| topic | почтальонка с сумкой | бодрая | idle, flow (письма летят), lag (гора писем) |
| external | onee-san в очках за стойкой | вежливо-холодная | idle, answer (свет, жест «прошу»), closed (жалюзи, «закрыто») |
| lock | вахтёрша со списком и шлагбаумом | строгая | idle, check (じー), deny (ладонь, ダメ!), allow (шлагбаум вверх) |
| parcel | картонная коробка с кошачьими ушками | плаксивая | idle, sad, wait, happy (зелёная наклейка, сердечки) |
| template | девочка с папкой карточек | — | idle, full, empty |

У каждого есть общие `catch` (сжатие и вытягивание) и `flinch` (вздрагивает), по 3 кадра. Состояния и имена файлов совпадают с режимом Пиксели, поэтому сцена переключается между режимами без правок.

## Эмоции и знаки
| Эмоция | Лицо | Знак |
|---|---|---|
| ждёт | полуприкрытые глаза, косится | облачко «…», капля пота, часы |
| спит, таймаут | глаза-дуги, рот «о», уши вниз | Z всплывают |
| цун | взгляд в сторону, надутые губы, румянец, руки скрещены | ふんっ, вена |
| бака | глаза `> <`, крик с клыком | バカ!, вена, пар из ушей |
| дере | слёзы в глазах, сильный румянец | ドキドキ, сердечки |
| рад | глаза-дуги, клык | ニャ♪ или キラキラ, сердечки, блёстки |
| шок | белые глаза-точки | ビクッ или ガーン, линии удара |
| грусть | слёзы, уши вниз | мрачные полосы над головой |
| озарение | открытый рот | «!», лучи над головой |

Японские звукоподражания — только украшение. Смысл всегда говорит субтитр на русском.

## Фоны = настроение
Восемь фонов 1080×1920 в `moe/bg/`. Фон меняется вместе с эмоцией сцены.

| Фон | Когда | Линия пола |
|---|---|---|
| sunset | титул, начало, «всё спокойно» | 1640 |
| night | ожидание, тишина, таймаут | 1600 |
| rain | упало, потеря | 1700 |
| sakura | успех, развязка | 1640 |
| flash | шок, резкий поворот | нет |
| idea | озарение | нет |
| alert | ошибка, отказ, «бака!» | нет |
| moe | цун/дере, смущение, вопрос пользователю | 1640 |

## Свет на персонаже
Без этого персонаж выглядит наклеенным. Для каждого фона в `moe/bg/backgrounds.json` лежит `light`:
- `amb` и `amb_k` — тон под фон: смешать картинку с её умножением на `amb` в доле `amb_k`. Ночью персонаж синеет, на закате теплеет.
- `rim` и `rim_dir` — контровой свет: полоса 7 px × масштаб по краю силуэта со стороны источника, размытие 1.2 px, непрозрачность 85 %.
- `backglow` — размытый на 26 px силуэт цвета источника за спиной, режим сложения.
- Тень на полу движок рисует сам: эллипс 260 × 48 × масштаб, чёрный 30 %, размытие 5 px.

## Голограммы
Статусы, вопросы и код показываются голо-панелью: стекло цвета роли с прозрачностью 15 %, рамка 3 px, точки по углам, строки развёртки. Заголовок набирается Inter Bold 26, строки — JetBrains Mono 25, важная строка — жёлтым. На светлых фонах под панелью лежит тёмное стекло 14 / 18 / 36 с альфой 200 из 255, иначе текст не читается. Появление: 0.3 с с мерцанием.

## Текст
- Субтитры: Inter Bold 50, белые, обводка 6 px почти чёрная, по центру на y = 1760. Караоке: непроизнесённые слова серые (150, 150, 165).
- Титул: «ЭПИЗОД N» Inter Bold 34 с линией под ним, название Inter Bold 92–100 со свечением, справа вертикальная японская строка Noto Serif CJK Bold 44.
- Звукоподражания: Noto Sans CJK Black, цветные, с белой обводкой 6 px, с поворотом ±10°.

## Камера и переходы
- Обычная сцена: медленный наезд 1.00 → 1.05 за сцену.
- Шок: белая вспышка 0.12 с, удар зумом 1.14 → 1.02 за 0.25 с, тряска 20 px, затухает за 0.7 с.
- Смена сцены: через чёрное (спокойные) или белое (резкие), 0.2–0.5 с.

## Звук
Фоновый аккорд под каждый фон (тёплый на закате, приглушённый ночью, мажор на развязке), музыкальная шкатулка в моэ-сценах, «мяу» на радости, стук сердца на ドキドキ, низкий удар на шоке, бипы голограмм.

## Перекраска
Правило то же, что в других режимах: движок перекрашивает **только нейтрально-серые пиксели** (r = g = b). В Моэ серым нарисованы части цвета роли: одежда, горшок, счёты, картотека, стойка, конвейер (206 / 164 / 236). Всё белое нарисовано тёплым белым 255 / 252 / 247 и не перекрашивается. Кожа, волосы, глаза и знаки цветные. Посылка нарисована картоном и не перекрашивается (`"tint": false`).

## Файлы
- `moe/<образ>/<состояние>_<i>.png` — 1040 × 1200 (2× логического холста 520 × 600). Опоры одинаковы у всех: `anchor` (520, 1120) — точка на полу, `top` (520, 300) — куда садится значок.
- Масштаб в кадре 1080 × 1920: 1.0 — персонаж около 780 px с ушами; два персонажа рядом — 0.85; крупный план — не больше 1.3. Масштабировать сглаживанием, не nearest.
- `moe/sprites.json` — состояния (`frames`, `fps`, `loop`), `rest`, `tint` для каждого образа.
- `moe/bg/*.jpg` и `moe/bg/backgrounds.json` — фоны, линия пола, свет.
- `moe/ui/badge-*.png` (144 px) и `moe/ui/glyph-*.png` (80 px, есть `glyph-heart`).
