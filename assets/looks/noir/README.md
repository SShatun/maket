# Нуар: пакет для движка (v2)

Кадр 1080×1920. Все PNG уже в финальном цвете, фильтры не нужны. Графика гладкая: масштабировать билинейно. Шрифт — `fonts/Inter-ExtraBold.otf`.

## Люди — `people/<role>/`
Роли: `detective` СЫЩИК, `pool` ПУЛ, `gateway` ШЛЮЗ, `cache` КЭШ, `db` БАЗА, `queue` ОЧЕРЕДЬ, `worker` ВОРКЕР, `woman` дама, `cop` полицейский, `bartender` бармен.
- `body_<pose>.png` 520×1100 — тело без головы. Позы: `stand`, `walk_0..7` (8 кадров/с), `sit`, `point`, `gesture`, `hands_up`, `cuffed`. Ноги в точке (251,1042). Смотрит влево; вправо — отразить по x вокруг 260.
- `head_<emo>.png` — голова. emo: `calm`, `talk`, `nervous`, `angry`, `guilty`. Ставится в `sprites.json → people.<role>.head_at.<pose>` (левый верхний угол, в координатах тела). Речь — чередовать `calm`/`talk` 6 раз в секунду.
- `bust_<emo>.png` 660×870 — крупный план по грудь, для допросной, кабинета, холла, хранилища.
- `sit`: ноги на полу (y 1042), сиденье стула на высоте около 760 в координатах тела.
- Тень под ногами: эллипс, правило в `style.json`.

## Клиенты — `clients/c0..c5/`
Серые безымянные люди (запросы): `body_stand`, `body_walk_0..7`, `head.png`, точки — `sprites.json → clients`.

## Свет на людях — `light/` + `scenes.json → <сцена>.people_light`
Люди рисуются со своим светом, поэтому в сцене их надо подсветить под фон. За кадр:
1. всех людей сцены (тела, головы, бюсты, клиентов) рисуем в один прозрачный слой;
2. цвет слоя × `tint` × (`floor` + (1 − `floor`) × карта света), карта — серый PNG в координатах кадра;
3. контровой свет: край = альфа − альфа, сдвинутая на `rim_px` в сторону, противоположную `rim_dir`; край × карта, закрашиваем цветом `rim`;
4. кладём слой на фон.
Образец — `reference_light.py`.

## Доска — `board_kit/`
Доска собирается под любое дело из JSON (`case_502.json`, `case_429.json` — примеры). Детали: `cork.png`, `card_blank.png` + `icons/<СЕРВИС>.png` (13 штук), `title_blank.png`, `note_yellow/white.png`, `pin_gold/red.png`, `arrow_twine/red.png`, `marker_circle.png`. Нитки движок рисует сам линиями — цвета, толщины, провис и скрутка в `spec.json`. `reference_renderer.py` — рабочий образец на Python, его и портировать. Анимация: нитки по одной (0,4 с каждая), потом обводка виновного, потом записки.

## Предметы и значки
- `props/`: `magnifier`, `photo`, `fingerprint`, `phone`, `typewriter`, `watch` (циферблат без стрелок — стрелки рисует движок: часовая 6 px, минутная 4 px, центр (110,150)), `flash` (вспышка, 3 кадра), `cuffs`.
- `icons/` над головой: `q`, `bang`, `dots`, `zzz`, `anger`, `sweat`.
- Неон: текст + свечение, правило мигания в `style.json`, пример в `fx/neon_example_*.png`.

## Ограничения
- Ходьба — на месте, видом 3/4; движок двигает спрайт по x.
- В `sit` стул не входит: он часть фона или ставится отдельно.
