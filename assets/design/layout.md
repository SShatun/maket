# Раскладка кадра

Кадр 1080×1920, 30 fps. Все координаты ниже — в пикселях этого кадра.

```
y=0     ┌──────────────────────────┐
        │  интерфейс площадки      │  safe-top 220
y=230   ├──────────────────────────┤  ← stage-top
        │                          │
        │  СЦЕНА (автокадрирование)│
        │                          │
y=1090  ├──────────────────────────┤  (1370, если кода нет)
y=1120  │  карточка кода           │  70…950 × 1120…1380
y=1380  ├──────────────────────────┤
y=1416  │  ( субтитры, центр x=510)│  высота 84
y=1500  ├──────────────────────────┤
        │  подпись, кнопки         │  safe-bottom 420
y=1920  └──────────────────────────┘
        x=70 … x=940, правее — лайки (safe-right 140)
```

## Сцена

- Сущности ставятся в координатах `at: [a, b]`: **a** — по горизонтали экрана (отрицательные левее), **b** — глубина (больше — ниже по экрану и ближе к зрителю).
- Движок сам подбирает масштаб и сдвиг так, чтобы все сущности с подписями поместились в зону сцены и не вылезли за safe-зоны даже после наезда камеры. Подгонять пиксели руками не нужно.
- Рабочая сетка: колонки через **2.5** по a, ряды через **4–5** по b. Три колонки (−2.5, 0, 2.5) — максимум для подписей 30px без наложения.
- Поток читается **сверху вниз**: кто инициирует — в верхнем ряду, хранилища и обработчики — ниже. Сайд-эффекты (кэш, база) разводятся влево и вправо в одном ряду.

## Подписи

- Блок в верхнем ряду: подпись **над** блоком. Хранилища, слоты, читатель: подпись **под**.
- Если над блоком стоит другой блок в той же колонке, подпись уходит **вбок** (`label_pos: "right"`), иначе она прилипнет к соседу.
- Две строки максимум: имя и статус. Статус — то, что сущность делает прямо сейчас.

## Карточка кода

- До 7 строк, строка до ~38 символов при 25px. Длиннее — сокращай код, а не шрифт.
- Если кода в сцене нет, убери блок `code`: сцена займёт место до y=1370.

## Субтитры

- Плашка-пилюля `ink`, центр по x=510 (оптический центр левее колонки лайков), y=1458.
- До 4 слов за раз. Длинную фразу движок сам делит на равные куски.
