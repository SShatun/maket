# Живые пиксели

В режиме Пиксели каждый образ — персонаж с лицом. Состояние читается по лицу и позе, а цвет роли и значок над образом остаются подсказкой. Превью в движении: группа ассетов Previews, `live-pixels.gif`.

## Персонажи и состояния

| Образ | Кто это | Состояния |
|---|---|---|
| person | человек с телефоном | idle (смотрит в телефон, моргает), wait (постукивает ногой, косится), surprised (руки вверх, «!»), happy (подпрыгивает) |
| service | машинка с экраном-лицом и счётами | idle, count (костяшки бегают), wait (глаза по сторонам), skip (пожимает плечами), bad (глаза крестиками, дым) |
| session | терминал, глаза — два курсора | idle (курсоры мигают), type (печатает строки), wait (часы на экране), sleep (Zzz) |
| dialog | окошко Yes/No | idle, impatient (подпрыгивает, мигает кнопкой Yes), closed (схлопывается, один раз) |
| queue | конвейер с головой-мотором | run (едет), stop (спит), full (коробки валятся через край) |
| branch | росток в горшке | idle, grow (растёт), pushed (улетает вверх, один раз) |
| db | шкаф-картотека, лицо на ярлыке | idle, give (выдвигает ящик, выдаёт карточку), empty (ящик пустой, пыль и паутина) |
| cache | рюкзак с карманом | idle, give (достаёт готовый ответ), miss (карман вывернут) |
| topic | лента с письмами, читатель на конце | idle, flow (письма едут), lag (письма копятся горой, читатель потеет) |
| external | здание чужой компании, окна — глаза, дверь — рот | idle, answer (дверь открыта, свет), closed (окна тёмные, табличка на двери) |
| lock | вахтёр со списком и шлагбаум | idle, check (сверяет по списку), deny (рука вперёд, «!», шлагбаум закрыт), allow (кивает, шлагбаум поднимается) |
| parcel | картонная посылка: клапаны и крест из скотча сверху, маленькая наклейка с адресом сбоку, лицо прямо на картоне | idle, sad (капля пота), wait (часы), happy (зелёная наклейка доставки, подпрыгивает) |
| template | папка с карточками способов доставки | idle, full (карточки торчат, довольна), empty (раскрыта, внутри ничего, пыль) |

У **каждого** персонажа есть два общих состояния:
- `catch` — поймал значение: сжатие и вытягивание, 3 кадра;
- `flinch` — отказали: вздрагивает с прищуром, 3 кадра.

Состояние `rest` в `sprites.json` указывает, к какому состоянию персонаж возвращается после разовых (`loop: false`).

## Правила рисования
- Холст 32 × 40 логических пикселей, сохранён в 12×: 384 × 480. В кадре 6×, то есть движок рисует с масштабом 0.5 и только nearest-neighbour.
- Опоры одинаковы у всех кадров персонажа: `anchor` — середина нижней линии, где он стоит; `top` — куда садится значок.
- Перекрашиваются только нейтрально-серые пиксели (r = g = b): тело, корпус, рамки. Лица, кожа, глаза, экраны, дым, пыль, «Zzz», часы нарисованы цветами палитры PICO-8 и не перекрашиваются.
- **Цвет материала не перекрашивается.** Если цвет сам говорит, что это за предмет (картон, дерево, кирпич), он рисуется цветами палитры, а не серым, и движок его не трогает. В `sprites.json` у такого образа стоит `"tint": false`. Состояние тогда передают лицо, наклейки и значок. Сейчас так нарисована только посылка: картон 246/198/146 (верх), 232/168/110 (лицевая грань), 196/136/88 (бок), 150/104/70 (скотч). Этих оттенков нет в базовых 16 цветах PICO-8: картон из них не собирается.
- Лицо всегда на светлом пятне (экран, ярлык, наклейка, кожа), если цвет роли может быть тёмным. Тогда глаза читаются при любой роли.
- Эффекты (дым, пыль, «Zzz», искры) не обводятся, чтобы оставаться лёгкими.
- Глаза: открыты, моргнул, широко (удивление), крестики (сломан), дуги (рад), грустные, сердитые, спит, взгляд в сторону или вниз.

## Файлы
`live/<образ>/<состояние>_<i>.png`, в `live/sprites.json` для каждого образа: `size`, `anchor`, `top`, `pixel`, `rest`, `states` со значениями `frames`, `fps`, `loop`.

## Шрифт режима
- Заглавные надписи, плашка-догадка, крупное число и подписи под персонажами набираются Press Start 2P: в нём полная кириллица.
- Субтитры набираются Inter Bold в пиксельной рамке. Причина та, которую назвал бэкенд: с СДВГ субтитры должны читаться с одного взгляда. У Press Start 2P строчные «м» и «н» почти не различаются, а в субтитрах это слова, а не короткие метки.
- Если субтитры всё же переводить на Press Start 2P, только с одним условием: не больше трёх слов на плашке и кегль от 36 px.
