# Objects-Pixel

Те же образы, значки и глифы в режиме «Пиксели» (человечки, палитра PICO-8), с теми же именами файлов. Перекрашиваются только нейтрально-серые пиксели. Кожа, экраны и обводка остаются как нарисованы. Масштаб: 12× логического пикселя, в кадре 6×, то есть 0.5× и только nearest-neighbour. Точки опоры лежат в `sprites.json` рядом.
