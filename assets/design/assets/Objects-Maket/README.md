# Objects-Maket

Образы в изометрии «Макета»: person, service, session, dialog, queue, branch, db, cache, topic, external, lock, плюс значки `badge-*` и глифы `glyph-*` для кубиков. Один PNG на образ, все состояния получаются окраской. Перекрашиваются только нейтрально-серые пиксели (r = g = b): `rgb × role / 255`. Масштаб: 100 px на юнит, в кадре 0.5×. Точки опоры `anchor` (пол под центром) и `top` (куда садится кубик или значок) лежат в `sprites.json` рядом.
