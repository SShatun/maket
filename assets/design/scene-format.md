# Формат сцены

Сцена — один JSON-файл. Рендер:

```
python -m maket render scenes/my-topic.json out/my-topic.mp4      # видео со звуком
python -m maket render scenes/my-topic.json out/x.mp4 --no-sfx    # без звука
python -m maket stills scenes/my-topic.json out/stills 2 8.5 14   # кадры для проверки
```

Нужны Python 3.10+, Pillow, NumPy и ffmpeg в PATH.

## Верхний уровень

| Поле | Тип | |
|---|---|---|
| `duration` | секунды | длина ролика |
| `entities` | список | сущности, в порядке появления |
| `code` | объект, необязательно | карточка кода |
| `events` | список | всё, что происходит |
| `captions` | список | `[начало, конец, "фраза"]` |

## Сущность

```json
{"id": "R", "kind": "block", "role": "consumer", "label": "читатель", "at": [0, 9],
 "label_pos": "below",
 "status": [[0, "ждёт"], [4.2, "handle(1)"]],
 "progress": [[0.5, 13.0, "handle(0)"]]}
```

| Поле | Значения | |
|---|---|---|
| `kind` | `block` · `slots` · `cylinder` | актор · очередь/буфер/кэш · база |
| `role` | `producer` · `consumer` · `buffer` · `storage` · `external` | цвет; `error` и `ok` только через события |
| `at` | `[a, b]` | a — горизонталь, b — глубина (см. «Раскладка кадра») |
| `label_pos` | `above` · `below` · `right` · `left` | по умолчанию: block над, остальные и consumer под |
| `status` | `[[t, "текст"], …]` | строка под именем, последняя с t ≤ сейчас |
| `progress` | `[[t0, t1, "подпись"], …]` | полоса прогресса со статусом; прячется через 0.6 с после t1 |
| `count`, `spacing` | для `slots` | число слотов (3), шаг (2.5) |
| `full_word` | для `slots`, `false` | не писать «забит», когда все слоты заняты (кэш) |

У `slots` под именем сам собой считается счётчик `n/count` (красный, когда всё занято), если `status` в этот момент пустой.

## Точки (anchor)

Куда можно отправить значение:

- `"A"` — верх сущности A;
- `"ch[0]"` — слот 0 сущности ch;
- `[a, b, z]` — точка в воздухе: ожидание у входа, проверка ключа над кэшем.

## События

| `do` | Поля | Что делает |
|---|---|---|
| `send` | `token`, `from`, `to`, `dur` (0.7), `arc`, `label`, `consume`, `waiting`, `role` | кубик летит из `from` в `to`. `token` — id, один на весь путь; `label` — что написано на кубике (по умолчанию id); `consume: true` — цель «съедает» кубик со вспышкой; `waiting: true` — по прилёте кубик ждёт и пульсирует красным; `role` — цветной кубик вместо белого |
| `block` | `target`, `until` | сущность краснеет и трясётся до `until` |
| `state` | `target`, `role`, `until` | временно перекрасить сущность (`error` промах, `ok` попадание) |
| `flash` | `target` | вспышка со щелчком |
| `focus` | `targets` | всё остальное притухает, камера наезжает на первую цель |
| `sfx` | `name`, `gain`, `dur` | звук без визуала: `whoosh` `land` `thud` `buzz` `pop` `chime` |

У любого события можно указать `"sound": false`.

## Код

```json
"code": {
  "lines": ["v, ok := cache.Get(id)", "if !ok {", "    v = db.Query(id)", "}"],
  "highlight": [[0, 0, "producer"], [2.0, 1, "error"], [4.0, 2, "storage"]]
}
```

`highlight` — `[t, номер строки, роль]`: с момента t подсвечена эта строка тинтом роли.

## Субтитры

```json
"captions": [[0.3, 3.6, "Три горутины пишут в канал с буфером на три."]]
```

Время слов внутри фразы распределяется пропорционально их длине. Когда будет готова озвучка, подгони `начало` и `конец` каждой фразы под реальный голос.
