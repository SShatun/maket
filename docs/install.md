# Установка maket с голосом

Нужен Mac с Apple Silicon, Go 1.25+, ffmpeg, Python 3 и `uv`. Проверка перед установкой назовёт недостающие программы и свободное место. Python 3.12.12 и 3.11.14 для голосовых окружений `uv` ставит сам. Устанавливать из корня репозитория:

```bash
bash tools/install.sh
```

По умолчанию всё лежит в `~/.local/share/maket`. Другое место: `bash tools/install.sh --prefix /путь/к/каталогу`. Повторный запуск продолжает прерванную загрузку и пропускает готовые модели. При ошибке скрипт печатает этап и команду для повторного запуска. Нужно не меньше 24 ГиБ свободного места; проверенная установка заняла 17 ГиБ. Время зависит от сети и Mac: ориентир 15–60 минут.

Проверка без сетевых загрузок прогоняет фразу через RUAccent, Qwen TTS, Whisper и проверку тембра ECAPA/Praat:

```bash
bash tools/install.sh --check
```

Первый ролик с голосом:

```bash
go run ./cmd/maket render scenes/rts-retry.json -o out/first.mp4 -workers 4
```

Для ролика без голоса достаточно Go и ffmpeg, установка моделей не нужна:

```bash
go run ./cmd/maket render scenes/rts-retry.json -o out/silent.mp4 -silent -workers 4
```

`-silent` убирает речь, но звуковые эффекты стиля остаются. Для полностью немого файла:

```bash
ffmpeg -i out/silent.mp4 -c:v copy -an out/no-audio.mp4
```

`maket.json` содержит общие настройки. Установщик создаёт `maket.local.json` с абсолютными путями к личной установке; файл игнорируется Git и перекрывает только указанные в нём поля. Перед переносом старой рабочей папки владельцу нужно сохранить прежнее содержимое `maket.json` в `maket.local.json` в своём checkout.

Модель Qwen с ударениями взята из публичного `siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf`, ревизия `c16b3af3db3095120efc1ebb73f6522442bcb3b1`, и локально переведена в MLX BF16 без квантования. RUAccent загружается из `ruaccent/accentuator`, Whisper из `mlx-community/whisper-large-v3-mlx`, ECAPA из `speechbrain/spkrec-ecapa-voxceleb`. Для всех моделей в скрипте закреплены ревизии, совпавшие с рабочими файлами владельца. Версии библиотек каждого окружения зафиксированы в `tools/voice/requirements/` по работающим окружениям владельца.


Speechify: `bash tools/install.sh --speechify` настраивает Python без дополнительных пакетов и проверяет наличие `espeak-ng` для преобразования словарных ударений в IPA; `--speechify --check` проверяет только локальные пути, без платного запроса.
В `maket.local.json` для выбора Speechify задайте `"voice_backend": "speechify"`, `"speechify_voice": "alexei"` и `"speechify_key_file": "/путь/к/speechify.key"`; ключ читается из файла только при запросе, без этого бэкенда по умолчанию остаётся Qwen. Для одного ролика бэкенд выбирает переменная окружения `MAKET_VOICE_BACKEND=speechify` поверх файла. Весь текст видео отправляется в облако Speechify одним запросом (до 2000 знаков), время слов приходит от сервиса; запись кешируется без обрезки, изменения темпа и вставки пауз.
Общий `voices/stress.json` и `stress` фразы передаются через [pronunciations](https://docs.speechify.ai/build/guides/text-to-speech/pronunciation): обычные замены через alias, проверяемые преобразования ударений через IPA; если IPA не подтверждает указанную гласную, нужна явная запись `"слово": "ipa:..."` в `stress`. Разные произношения одного слова в одной записи пока не поддержаны; для независимой проверки слов нужны `tts_python` и `whisper_model`, для внешней очереди TTS/ASR можно задать `MAKET_BUSY_CHECK` с путём к проверочному shell-скрипту (0 занят, 1 свободен).

Обычная установка сохраняет прежний набор окружений Qwen; Speechify настраивается только через `--speechify`, который не устанавливает системные зависимости. Если `espeak-ng` отсутствует, установите его самостоятельно. Параметры голоса сцены / `-voice` и `seed` не действуют на Speechify: выбирается `speechify_voice` (по умолчанию `alexei`), движок печатает одно предупреждение об обоих ограничениях. Облачный запрос не ждёт `MAKET_BUSY_CHECK` и не занимает `lockMachine`; локальный синтез и ASR сохраняют прежнюю очередь.

Ключ кеша Speechify включает код `tools/voice/speechify.py`; его изменение требует новой записи. Слова сопоставляются с отметками по пересечению позиций символов исходного текста: части слова объединяются, одна отметка на несколько слов даёт общее время с предупреждением. Если отметки слова нет, используется ближайшая с предупреждением; распознавание остаётся отдельной проверкой содержания.
