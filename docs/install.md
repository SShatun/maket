# Установка maket с голосом

Нужен Mac с Apple Silicon, Go 1.25+, ffmpeg, Python 3 и `uv`. Проверка перед установкой назовёт недостающие программы и свободное место. Python 3.12.12 и 3.11.14 для голосовых окружений `uv` ставит сам. Устанавливать из корня репозитория:

```bash
bash tools/install.sh
```

По умолчанию всё лежит в `~/.local/share/maket`. Другое место: `bash tools/install.sh --prefix /путь/к/каталогу`. Повторный запуск продолжает прерванную загрузку и пропускает готовые модели. При ошибке скрипт печатает этап и команду для повторного запуска. Нужно не меньше 24 ГиБ свободного места; проверенная установка заняла 17 ГиБ. Время зависит от сети и Mac: ориентир 15–60 минут.

Проверка без сетевых загрузок прогоняет фразу через RUAccent, Qwen TTS, Whisper и проверку тембра ECAPA/Praat:

```bash
bash tools/install.sh --check
```

Первый ролик с голосом:

```bash
go run ./cmd/maket render scenes/rts-retry.json -o out/first.mp4 -workers 4
```

Для ролика без голоса достаточно Go и ffmpeg, установка моделей не нужна:

```bash
go run ./cmd/maket render scenes/rts-retry.json -o out/silent.mp4 -silent -workers 4
```

`-silent` убирает речь, но звуковые эффекты стиля остаются. Для полностью немого файла:

```bash
ffmpeg -i out/silent.mp4 -c:v copy -an out/no-audio.mp4
```

`maket.json` содержит общие настройки. Установщик создаёт `maket.local.json` с абсолютными путями к личной установке; файл игнорируется Git и перекрывает только указанные в нём поля. Перед переносом старой рабочей папки владельцу нужно сохранить прежнее содержимое `maket.json` в `maket.local.json` в своём checkout.

Модель Qwen с ударениями взята из публичного `siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf`, ревизия `c16b3af3db3095120efc1ebb73f6522442bcb3b1`, и локально переведена в MLX BF16 без квантования. RUAccent загружается из `ruaccent/accentuator`, Whisper из `mlx-community/whisper-large-v3-mlx`, ECAPA из `speechbrain/spkrec-ecapa-voxceleb`. Для всех моделей в скрипте закреплены ревизии, совпавшие с рабочими файлами владельца. Версии библиотек каждого окружения зафиксированы в `tools/voice/requirements/` по работающим окружениям владельца.


Speechify: `bash tools/install.sh --speechify` настраивает Python без дополнительных пакетов и проверяет наличие `espeak-ng` для преобразования словарных ударений в IPA; `--speechify --check` проверяет только локальные пути, без платного запроса.
В `maket.local.json` для выбора Speechify задайте `"voice_backend": "speechify"`, `"speechify_voice": "alexei"` и `"speechify_key_file": "/путь/к/speechify.key"`; ключ читается из файла только при запросе, без этого бэкенда по умолчанию остаётся Qwen. Для одного ролика бэкенд выбирает переменная окружения `MAKET_VOICE_BACKEND=speechify` поверх файла. Весь текст видео отправляется в облако Speechify одним запросом (до 2000 знаков), время слов приходит от сервиса; запись кешируется без обрезки, изменения темпа и вставки пауз.
Общий `voices/stress.json` и `stress` фразы передаются через [pronunciations](https://docs.speechify.ai/build/guides/text-to-speech/pronunciation): обычные замены через alias, проверяемые преобразования ударений через IPA; если IPA не подтверждает указанную гласную, нужна явная запись `"слово": "ipa:..."` в `stress`. Разные произношения одного слова в одной записи пока не поддержаны; для независимой проверки слов нужны `tts_python` и `whisper_model`, для внешней очереди TTS/ASR можно задать `MAKET_BUSY_CHECK` с путём к проверочному shell-скрипту (0 занят, 1 свободен).

Обычная установка сохраняет прежний набор окружений Qwen; Speechify настраивается только через `--speechify`, который не устанавливает системные зависимости. Если `espeak-ng` отсутствует, установите его самостоятельно. Параметры голоса сцены / `-voice` и `seed` не действуют на Speechify: выбирается `speechify_voice` (по умолчанию `alexei`), движок печатает одно предупреждение об обоих ограничениях. Облачный запрос не ждёт `MAKET_BUSY_CHECK` и не занимает `lockMachine`; локальный синтез и ASR сохраняют прежнюю очередь.

Ключ кеша Speechify включает код `tools/voice/speechify.py`; его изменение требует новой записи. Слова сопоставляются с отметками по пересечению позиций символов исходного текста: части слова объединяются, одна отметка на несколько слов даёт общее время с предупреждением. Если отметки слова нет, используется ближайшая с предупреждением; распознавание остаётся отдельной проверкой содержания.

Yandex SpeechKit: `bash tools/install.sh --yandex` добавляет настройки Python без дополнительных пакетов; `--yandex --check` проверяет локальные пути без платного запроса. Создайте сервисный аккаунт с ролью [`ai.speechkit-tts.user`](https://yandex.cloud/en/docs/iam/roles-reference#ai-speechkit-tts-user) на его каталог и API-ключ со [scope `yc.ai.speechkitTts.execute`](https://yandex.cloud/en/docs/iam/concepts/authorization/api-key). Сохраните секретную часть ключа одной строкой в отдельном файле, например `~/.local/share/maket/yandex.key`, с правами `600`. Ключ читается только из этого файла и не попадает в команды, логи или кеш.

В `maket.local.json` задайте `"yandex_python": "/usr/bin/python3"`, `"yandex_voice": "anton"`, `"yandex_role": "good"` и `"yandex_key_file": "/абсолютный/путь/к/yandex.key"`. Для постоянного выбора добавьте `"voice_backend": "yandex"`, для одного запуска используйте `MAKET_VOICE_BACKEND=yandex`. По умолчанию остаётся Qwen; `--yandex` не меняет выбранный бэкенд. Параметры голоса сцены / `-voice` и `seed` игнорируются с одним предупреждением, используются `yandex_voice` и `yandex_role` (по умолчанию `anton` и `good`).

Каждая фраза отправляется отдельным запросом [REST v3](https://aistudio.yandex.ru/en/docs/speechkit/tts-v3/api-ref/Synthesizer/utteranceSynthesis), PCM приходит в частоте движка без пересчёта. Ударения из `voices/stress.json` и `stress` фразы превращаются в `+` перед гласной; настройка фразы имеет приоритет. Явные паузы сцены сохраняются. Для времени слов обязательны `tts_python` и `whisper_model` от локальной установки: Whisper проходит через `MAKET_BUSY_CHECK` (0 занят, 1 свободен) и машинную блокировку, облачный запрос их не занимает. Расхождения распознавания выводятся предупреждениями. Запись кешируется в `.cache/voice/yandex/<hash>` с учётом голоса, роли, текстов, частоты и кода `tools/voice/yandex.py`; ключ API в хеш не входит. Строка `take:` показывает голос, роль и число отправленных символов, включая разметку ударений, для этой записи.

Fish Audio: `bash tools/install.sh --fish` добавляет настройки Python без дополнительных пакетов; `--fish --check` проверяет пути и наличие ffmpeg без сетевого запроса. В `maket.local.json` задайте `"fish_python": "/usr/bin/python3"`, `"fish_model": "s2.1-pro-free"` и `"fish_key_file": "/абсолютный/путь/к/fish.key"`. Сохраните ключ одной строкой в этом отдельном файле с правами `600`: он читается только при запросе и не попадает в команды, логи или кеш. Установщик сохраняет выбранный бэкенд; Fish включается через `"voice_backend": "fish"` или `MAKET_VOICE_BACKEND=fish`.

Paper требует ключ Fish: сохраните его в `~/.local/share/maket/fish.key` и укажите этот абсолютный путь в `fish_key_file`. Стиль сам выбирает Fish через свой `look.json`, когда `MAKET_VOICE_BACKEND` не задана, даже если локально выбран другой бэкенд. Модель берётся из `fish_model`; установщик задаёт `s2.1-pro-free`. Имя выбранной модели передаётся в обязательном заголовке `model`. Голоса `cartman` и `butters` уже описаны в `voices/` через библиотечный `reference_id`, образцы для них не нужны. Назначение голосов персонажам описано в [paper.md](styles/paper.md).

Голос сцены и `-voice NAME` выбирают папку в `voices/`, как для Qwen: `ref_audio` (обычно `ref.wav`) и `ref_text` из `voice.json` отправляются вместе с каждой фразой. Для библиотечного голоса вместо образца и его текста отправляется только `reference_id`. В Paper `speaker` выбирает `voice` персонажа, а `-voice` заменяет только голос по умолчанию. Библиотечные голоса без образца доступны только в Fish; остальные бэкенды возвращают понятную ошибку с именем голоса. `seed` игнорируется. Применяются замены `spell`; поддержка русского `+` и комбинируемого акута не описана в [управлении произношением Fish](https://docs.fish.audio/developer-guide/core-features/fine-grained-control), поэтому отправляется текст без этих знаков, а `stress` и RUAccent не используются. Ограничения выводятся одним предупреждением.

На фразу приходится один запрос MessagePack без автоматических повторов. [API Fish](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech) возвращает WAV 44,1 кГц, ffmpeg переводит его в моно PCM 48 кГц движка; темп не меняется. Для времени слов нужны локальные `tts_python` и `whisper_model`. Whisper учитывает `MAKET_BUSY_CHECK` и машинную блокировку; облачный запрос их не занимает. Паузы и предупреждения распознавания обрабатываются как у Yandex. Кеш `.cache/voice/fish/<hash>` учитывает модель, имя папки и `reference_id` либо хеши образца и его текста для каждой фразы, тексты фраз, частоту и `tools/voice/fish.py`; `seed` и ключ API в хеш не входят. Строки фраз показывают выбранный голос; `take:` показывает модель, темп и число отправленных символов для записи.
