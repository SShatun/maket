# Сцена для движка maket

Сцена — один JSON-файл. По нему движок пишет голос, собирает кадры и звук и отдаёт вертикальный mp4 1080×1920, 30 кадров в секунду.

## Команды

```
go run ./cmd/maket styles [-root DIR]
go run ./cmd/maket voice  <scene.json> [-voice NAME] [-seed N] [-root DIR]
go run ./cmd/maket stills <scene.json> -o <dir> [-voice NAME] [-silent] [-root DIR] <t1> [t2 …]
go run ./cmd/maket render <scene.json> -o <out.mp4> [-voice NAME] [-seed N] [-silent] [-workers N] [-root DIR]
```

- Флаги идут сразу после сцены, секунды кадров — в самом конце. Флаг после первой секунды уже не флаг: `stills: bad time "-root"`.
- `-root` — корень репозитория maket. Из него берутся `assets/`, `voices/`, `tools/voice/`, `maket.json`, туда же пишется кэш `.cache/voice/`.
- `voice` печатает строки `N start end текст`, по одной на фразу, затем строки `tempo phrase N: …` и последней строкой путь дорожки. Из первых берутся секунды для `stills`. Строка `tempo` говорит, откуда кусок (`main` — общая запись, `re-voiced` — фраза записана отдельно, с каким `seed`), темп чистой речи в слогах в секунду до и после выравнивания, растяжение `atempo` и целевой темп — медиана кусков общей записи. Весь текст пишется одним дублем: если в нём потеряна или обрезана фраза или темп фраз расходится больше чем на 15 %, движок записывает весь текст заново с seed +100 и +200 и берёт лучший из трёх дублей; отдельно по одной пишутся только фразы, потерянные и в лучшем дубле. Затем каждый кусок, который отличается от цели больше чем на 3 %, растягивает к цели, но не больше чем на 10 %. В той же строке `speech A → B dB` — громкость речи куска до и после выравнивания: каждый кусок приводится к целевой громкости `target` — медианной громкости речи кусков общей записи —, если расходится больше чем на 1 дБ, без пика выше −1 дБ.
- `stills` пишет `still_<t>.png` в папку `-o`. `render` печатает путь mp4.
- `-silent` убирает голос. Время тогда считается по буквам: слово длится (букв + 2) / 14 с, между фразами 0.35 с плюс `pause`, ролик начинается с 0.2 с. Кадры не совпадают с роликом с голосом. Проверочные кадры снимаются с тем же голосом, что и ролик.
- Голос кэшируется по тексту всех фраз, образцу, модели и seed. Повторный `render` после `stills` голос заново не пишет. Правка текста любой фразы пишет голос заново.
- Предупреждения выводятся в stderr с префиксом `maket:`. `nothing happens from A to B s` значит, что в сцене больше 3 секунд нет ни одного момента: туда нужно событие. Моментом считается всё, у чего есть время: `at` и `until` событий, `appear`, смена `status`, `states`, `roles` и `badges`, подсветка и `appear` строк кода, `at` и `card_at` ответа. Отсчёт идёт с начала фразы 1, а карточка догадки моментом не считается. Поэтому к ~3 с нужен первый момент, обычно `appear` сущностей на фразе 2 (появление по умолчанию моментом не считается). В конце промежуток от последнего момента до конца ролика (`hold` после последней фразы) тоже не длиннее 3 с: `card_at` ответа или `focus` ставят на последнюю фразу. `phrase N: not heard: …` значит, что распознавание не нашло слово. Сначала сверить с текстом фразы: распознавание путает термины.

## Верх сцены

| Поле | Что |
|---|---|
| `style` | `pixel` или `maket` |
| `look` | стилистика Пикселей: папка `assets/looks/<look>/` со своими персонажами и необязательными `look.json` (фон, цвета, роли) и `badges/`; без поля — `assets/live`; с `maket` — ошибка |
| `guess` | `{"text": "Ресинк сломан?"}` — неверная догадка крупно в начале |
| `answer` | `{"at": момент, "card_at": момент, "text": "Шаблон пустой", "badge": "ok"\|"bad"\|"question"\|"wait", "size": 64}` — в `at` догадка зачёркивается, в `card_at` появляется ответ (без него через 0.7 с). Без `guess` ответ не рисуется. `size` по умолчанию 70. `badge` рисуется только в Пикселях |
| `phrases` | что говорит голос, по порядку |
| `entities` | кто в кадре |
| `events` | что происходит: `{"at": момент, "do": "move", …}` |
| `shots` | последовательность кадров Пикселей; заменяет `entities` и `events`, у каждого кадра свои `cast` и `do` |
| `code` | карточка кода внизу кадра, по желанию |
| `hold` | секунд после последней фразы, по умолчанию 1.5 |
| `seed` | seed голоса и раскладки толпы, по умолчанию 42 |
| `voice` | папка в `voices/`. Не писать: тогда голос берётся из `maket.json`, а `-voice` его меняет |

Длина ролика — конец последней фразы плюс `hold`. Полей `duration` и `captions` нет: время задают фразы.

## Фразы

```json
{"text": "ресинк не сломан. расчёт берёт методы из шаблона.", "caption": "методы из шаблона", "pause": 0.3, "stress": {"шаблона": "шабло́на"}}
```

- `text` — то, что звучит. Пишется по-русски, как говорят: «рид райт», а не «read-write», «йес», а не «Yes». Без кавычек-ёлочек и скобок.
- `caption` — субтитр в 1–3 слова. Полный текст рядом с голосом мешает.
- `pause` — тишина перед фразой, в секундах.
- `stress` — ударение для одного слова, когда модель ставит его неверно. Ударения для всех роликов голоса лежат в `voices/<голос>/voice.json`. Остальные ударения расставляет RUAccent; его выключает поле `"ruaccent": false` в `maket.json`, и тогда ударения берутся только из этих словарей.

## Моменты

Любое время в сцене — момент: число секунд или строка, привязанная к слову фразы.

| Запись | Когда |
|---|---|
| `"p4"` | начало фразы 4 (фразы нумеруются с 1) |
| `"p4.end"` | конец фразы 4 |
| `"p4:шаблон"` | начало слова «шаблон» в фразе 4. Регистр не важен, ё = е |
| `"p8:она#2"` | второе «она» в фразе 8 |
| `"p7:йес-0.7"`, `"p4.end+1.5"` | сдвиг в секундах |
| `2.5` | секунды от начала, обычно только `0` |

Слова нет в фразе — ошибка `phrase N has no word`. Привязывать события к словам, а не к секундам: тогда они идут вместе с голосом.

Значение во времени — `[момент, значение]`, список таких пар меняет значение по ходу ролика: `"status": [[0, "ждёт"], ["p4:считает", "считает"]]`. Третий элемент `"hold"` у состояния Пикселей держит последний кадр анимации.

## Точки

Где событие начинается и кончается: `"S"` — сущность, `"Q[1]"` — слот сущности `slots`, слоты с 0, `[x, y]` — координаты (в Макете ещё `[a, b, z]`).

## Общее для двух стилей

| Событие | Поля | Что |
|---|---|---|
| `number` | `at`, `until`, `text`, `sub`, `pos`, `tone` | большое число в рамке: `"text": "0", "sub": "методов в шаблоне"`. `pos: [x, y]` задаёт центр, `tone`: `accent` (по умолчанию в Пикселях), `ok`, `error` |
| `focus` | `at`, `targets` | всё, кроме целей, притухает. Обычно на последней фразе |

`code`:
```json
{"lines": ["POST /v1/item-resync", {"text": "template/methods/get: 0", "appear": "p5"}],
 "highlight": [["p2", 0, "yel"], ["p5", 1, "error"], ["p7", 0, "ok"]]}
```
Строка кода — настоящий вывод, лог или запрос, не иллюстрация. Подсветка `[момент, номер строки с 0, тон]`, тоны: `yel`, `lav`, `error`, `ok`; `off` снимает подсветку. Тоны ролей (`producer`, `consumer`, `buffer`, `storage`, `external`) есть только в Макете, в Пикселях такая строка не подсветится.

## Пиксели

Живые персонажи. Подходит, когда сюжет «кто и почему»: кто-то ждёт, падает, пропускает, не пускает.

Сущность:
```json
{"id": "W", "kind": "service", "role": "producer", "label": "расчёт", "at": [760, 640],
 "status": [[0, "ждёт"], ["p3:запускается", "считает"]],
 "states": [[0, "idle"], ["p3:запускается", "count"], ["p3:пропускает", "skip"]],
 "roles": [["p3:пропускает", "error"], ["p4", "producer"]],
 "badges": [["p3:пропускает", "bad"], ["p4", null]],
 "appear": "p2"}
```
- `at` — пиксели кадра, точка ног. Персонаж поднимается над ногами на 456 px и шириной 384 px, подпись и статус стоят на 40–70 px ниже ног. Поэтому ноги ставят по x от 250 до 830, по y от 650 до 1180, с кодом и без. Выше 650 пузырь `say` заходит на полосу прогресса 112…136. Ниже 1300 персонаж не притухает от `focus`, `number` и догадки. Сколько персонажей и где они стоят, решает история: один герой с вещью, двое друг напротив друга или толпа — у движка ограничения нет. В кадрах `shots` персонажи ставятся свободно, с любым `size`.
- `role`: `external` (белый), `producer` (тёмно-зелёный), `consumer` (сиреневый), `buffer` (оранжевый), `storage` (голубой), `error` (красный), `ok` (ярко-зелёный). Красное появляется в ролике один раз — там, где ломается.
- `status` — подпись под персонажем, `badges` — значок над головой: `bad`, `ok`, `question`, `wait`, `null` убирает значок.

Персонажи (`kind`) и их состояния. У всех есть ещё `catch` (ловит прилетевшее) и `flinch` (вздрагивает от отказа):

| kind | кто | состояния |
|---|---|---|
| `person` | человек с телефоном | `idle`, `wait`, `surprised`, `happy` |
| `service` | сервис, работник | `idle`, `count`, `wait`, `skip`, `bad` |
| `session` | терминал | `idle`, `type`, `wait`, `sleep` |
| `dialog` | окошко Yes/No | `idle`, `impatient`, `closed` |
| `queue` | конвейер | `run`, `stop`, `full` |
| `branch` | ветка-росток | `idle`, `grow`, `pushed` |
| `db` | картотека | `idle`, `give`, `empty` |
| `cache` | карман с ответами | `idle`, `give`, `miss` |
| `topic` | лента писем | `idle`, `flow`, `lag` |
| `external` | чужой сервис | `idle`, `answer`, `closed` |
| `lock` | вахтёр со списком | `idle`, `check`, `deny`, `allow` |
| `parcel` | товар-посылка, картонная, не перекрашивается | `idle`, `sad`, `wait`, `happy` |
| `template` | папка с карточками | `idle`, `full`, `empty` |
| `tariff` | ценник с ₽, нарисован сервисом | `idle`, `happy` |

Список берётся из `assets/live/sprites.json`, полный с подписями и синонимами — `go run ./cmd/maket char list [-look L]`. Незнакомое состояние — ошибка `has no state`. Нужного персонажа нет — его дорисовывают по `docs/characters.md`.

События:

| Событие | Поля | Что |
|---|---|---|
| `move` | `from`, `to`, `label`, `dur` (0.6), `until` | ящик с подписью летит из точки в точку. Точка-сущность — середина персонажа, на 180 px выше ног |
| `say` | `target`, `text`, `until` (+2 с), `dx` | реплика пузырём |
| `state` | `target`, `state`, `hold` | сменить состояние |
| `role` | `target`, `role`, `until` | сменить цвет, после `until` вернуть |
| `shake` | `target` | тряхнуть |
| `split` | `target`, `into`, `dur` (0.6) | цель вздрагивает и исчезает. Две сущности из `into` появляются в её точке и за `dur` выезжают в свои `at`: своего `appear` у них нет, рисуются в 0.75 размера |

```json
{"at": "p5:пополам", "do": "split", "target": "D", "into": ["D1", "D2"], "dur": 0.6}
```

### Последовательность кадров

В Пикселях вместо общих `entities` и `events` можно задать `shots`. Без `shots` сцена рисуется по прежним правилам.

```json
{"style": "pixel", "seed": 42,
 "phrases": [{"text": "Магнит собрал 280 заказов в одно поручение."}],
 "shots": [
  {"at": "p1:Магнит",
   "place": {"wall": [45, 40, 35], "floor": 620, "ground": [70, 60, 48]},
   "cast": [
    {"crowd": {"kind": "parcel", "count": 12, "box": [60, 650, 1020, 1650], "size": [0.3, 0.7], "rows": 4, "state": "idle"}}],
   "do": [{"at": "p1:Магнит", "do": "zoom", "to": 1.15, "dur": 1}]},
  {"at": "p1:280",
   "place": {"wall": [45, 40, 35], "floor": 1500, "ground": [70, 60, 48]},
   "cast": [{"id": "M", "kind": "parcel", "at": [540, 1420], "size": 2.2, "state": "idle", "label": "280 заказов"}],
   "do": [
    {"at": "p1:280", "do": "text", "text": "280", "pos": [540, 480], "size": 150, "tone": "accent"},
    {"at": "p1:280", "do": "text", "text": "заказов", "pos": [540, 620], "size": 36},
    {"at": "p1:одно", "do": "walk", "target": "M", "to": [700, 1500], "dur": 1.2}]}
 ]}
```

- `at` кадра использует обычный формат моментов. Первый кадр начинается в 0 независимо от своего `at`; запись момента всё равно проверяется. Следующие начала после расчёта времени должны строго возрастать. Кадр заканчивается на следующей склейке, последний длится до конца ролика. Начало кадра считается моментом для предупреждения `nothing happens`.
- `place` принимает имя картинки из `backdrops` выбранной стилистики или объект с `wall`, `floor`, `ground`. Картинка растягивается на весь кадр без сглаживания; `floor` в её записи указывает режиссёру линию пола, при `null` пола нет. В объекте `wall` и `ground` принимают RGB `[r, g, b]` или имя из `palette`. `floor` задаёт линию пола от 600 до 1900; при `null` или без `floor` весь фон залит цветом стены. Неизвестное имя фона или цвета останавливает сборку до рендера с перечнем известных имён.
- `cast` задаёт состав заново на каждой склейке. `id` уникален внутри кадра и может повторяться в других кадрах. `kind` берётся из `assets/live` или выбранного `look`. `at: [x, y]` задаёт точку ног во всём кадре 1080×1920. `size` от 0.2 до 4, по умолчанию 1, масштабирует персонажа без сглаживания; положения подписей, пузырей и прилёта ящика учитывают размер.
- `state` задаёт начальную анимацию, без него используется `rest` персонажа. `role`, `label`, `status`, `states`, `roles` и `badges` имеют тот же формат, что у сущностей. Состояние, цвет и положение из предыдущего кадра не переносятся. Отдельного `appear` у состава нет: он сразу виден, без всплывания и звука появления.
- `crowd` занимает одну запись `cast`. `count` фигур раскладываются в `rows` рядов внутри `box: [x0, y0, x1, y1]`; это границы точек ног. В верхнем ряду размер `size[0]`, в нижнем `size[1]`. Лёгкое смещение по горизонтали зависит от `seed`; одинаковый seed даёт одинаковую раскладку. У фигур толпы нет доступных для событий id.
- `do` допускает прежние события Пикселей и элементы кадра из таблицы ниже. Все ссылки на участников, включая `into` у `split`, относятся только к этому кадру. Момент начала события должен попадать в кадр; действие и `until` обрезаются на склейке. Половины `split` — обычные участники `cast` этого кадра со своими `id`, `at`, `size` и `label`: без записи в `cast` ошибка `unknown entity`. До деления они скрыты, после него выезжают в свои `at` с размером `0.75 × size`.
- `zoom` использует числовое `to` не меньше 1 и положительное `dur`. Масштаб плавно меняется от текущего до `to` вокруг центра кадра или `pos: [x, y]`, затем сохраняется до следующего наезда или склейки. Масштабируются фон, персонажи, подписи, пузыри, числа, линии, свободный текст и панели. На склейке камера сбрасывается.
- `walk` перемещает `target` в `to: [x, y]` за положительное `dur`, с покачиванием по y до 2 px. После шага участник остаётся в конечной точке. Порядок рисования определяется текущей точкой ног: дальние участники рисуются первыми.
- При `shots` карточка `code` и её звуки скрыты; логи показываются строками `panel`. Затемнение числа, догадки, ответа и `focus` покрывает весь кадр. `guess`, `answer`, субтитры и прогресс остаются поверх кадра и не увеличиваются камерой.

Элементы `do` доступны только в кадрах. Они появляются в `at`, остаются до `until` или склейки и увеличиваются камерой. Координаты заданы в пикселях кадра.

| Событие | Поля | Что |
|---|---|---|
| `line` | `from: [x, y]`, `to: [x, y]`, `kind`, `tone` | линия толщиной 6 px, с шагом 3 px; `kind`: `solid` (по умолчанию), `dash`, `arrow` |
| `text` | `text`, `pos: [x, y]`, `size`, `tone` | свободная надпись шрифтом стилистики; `pos` задаёт центр, `size` по умолчанию 28 |
| `panel` | `box: [x0, y0, x1, y1]`, `title`, `lines`, `fill`, `tone` | рамка толщиной 6 px; `fill`: `card` (по умолчанию), `accent`, `error`; заголовок и строки подгоняются под ширину |

У `panel` поле `tone` (`ink`, `accent`, `ok`, `error`) красит рамку и заголовок, а `fill` независимо задаёт заливку: `tone: "error"` с `fill: "card"` даёт красную табличку на тёмном фоне.

`tone` у линий, надписей и строк панели: `ink`, `accent`, `ok`, `error`. Без тона линии и надписи используют `ink`, строки панели приглушены. Цветной тон строки также подсвечивает её фон. В панели без строк заголовок стоит по центру, со строками наверху. Строки используют моноширинный шрифт карточки кода; ещё не появившиеся строки не занимают места.

```json
{"at": "p2", "do": "panel", "box": [80, 1040, 1000, 1320], "title": "Лог расчёта", "fill": "card",
 "lines": [{"text": "template/methods/get: 0", "appear": "p2:шаблон", "tone": "error"},
           {"text": "item-resync: queued", "appear": "p3", "tone": "accent"}]}
```

Выход `panel`, `text` и пузырей `say` за x 0…1080 или y 140…1640 вызывает предупреждение `maket:` в stderr: номер кадра, событие, сторона и максимальный выход в пикселях. Проверка учитывает камеру, движение и появление пузыря на частоте рендера. Сборка продолжается; обрезанные краем персонажи предупреждения не вызывают.

### Описание стилистики

`go run ./cmd/maket styles` показывает стили `pixel` и `maket`, а у Пикселей стилистику по умолчанию (`assets/live`) и папки `assets/looks/*`. Для каждой выводятся `about`, имена `palette` и `backdrops`. Эти поля необязательны в `look.json`; прежние `theme` и `roles` сохраняют своё значение. `palette` задаёт именованные цвета мест и не меняет тему сама по себе.

```json
{"about": "Посылки, шаблоны и сервисы для историй о доставке.",
 "palette": {"warehouse": [61, 48, 35], "shelf": [96, 73, 48]},
 "backdrops": {"склад": {"file": "backdrops/склад.png", "floor": 1420},
               "небо": {"file": "backdrops/небо.png", "floor": null}}}
```

Пути картинок отсчитываются от папки стилистики. Место выбирается как `"place": "склад"` или `"place": {"wall": "warehouse", "floor": 1420, "ground": "shelf"}`. Пока у стилистики по умолчанию нет картинок мест, её `backdrops` пустой.

## Макет

Изометрия, кубики. Подходит, когда сюжет «где и сколько»: что где лежит, куда течёт, сколько чего.

Сущность: `kind` — `block` (кубик 1.8 клетки), `slots` (ряд ячеек по 2 клетки, `count` 3, `spacing` 2.5 между центрами), `cylinder` (хранилище, 2 клетки). `at: [a, b]` — клетки сетки: a — по горизонтали (минус левее), b — глубина (больше — ниже). Кадр сам подгоняет масштаб. Колонки через 2.5, ряды через 4–5, не больше трёх колонок. `label_pos`: `above`, `below`, `left`, `right`. Роли те же, что в Пикселях. `status` и `appear` — как там. У `slots` без `status` подпись считает токены сама, `2/3`. У полных слотов подпись краснеет и пишет «забит», `"full_word": false` убирает это слово.

`slots` стоит по центру своего `at` и занимает по a от `−(count−1)·spacing/2 − 1` до `+(count−1)·spacing/2 + 1`. `spacing` меньше 2 — ячейки налезают друг на друга. Ряд из трёх ячеек занимает всю ширину трёх колонок: соседей ставят в другой ряд, на 4–5 по b. Число ячеек во времени не меняется, а сущность нельзя спрятать. Рост показывают второй `slots`, у которого `appear` позже.

| Событие | Поля | Что |
|---|---|---|
| `send` | `token`, `label`, `from`, `to`, `dur`, `consume`, `arc`, `waiting`, `role` | кубик-токен летит. Один `token` — один кубик: следующий `send` с тем же `token` везёт его дальше. `consume` — токен исчезает в цели. `arc` — высота дуги полёта (1.6, внутри одной сущности 0.8). `waiting` — токен остаётся у цели, меньше и мигает красным: ждёт. `role` красит токен в цвет роли. Подпись `label` короткая, 1–5 знаков: она рисуется на кубике. Подпись берётся из первого `send` этого `token`, без `label` это имя токена; `label` в следующих `send` ничего не меняет |
| `block` | `target`, `until` | цель красная и заблокирована до `until`, без него до конца |
| `state` | `target`, `role`, `until` | цель меняет цвет до `until`, без него до конца |
| `flash` | `target` | вспышка |
| `shot` | `target`, `zoom` (1.3), `dur` (0.6), `until` | камера наезжает и возвращается в `until`; без `until` остаётся до конца |

## Что движок даёт истории

Форму ролика задаёт история, движок её не навязывает. Ниже то, на что он способен:
- `shots` — ролик из кадров, у каждого своё место, свой состав и своё действие. Общий план — толпа `crowd` или несколько мелких фигур на дальнем полу; крупный план — один участник с `size` 2–3, его может обрезать край кадра. Склейка — следующий кадр; наезд — `zoom`; переход по сцене — `walk`.
- Предметы истории рисуются элементами кадра: экран, кнопка, табличка, лог — `panel`; стрелка, черта, пунктир — `line`; вопрос или число крупно прямо в кадре — `text` с `size` 100–150 и `tone`. `number` и `focus` притушают весь кадр вместе с персонажами и надписями, кроме целей `focus`: в кадрах число ставят `text`, а `number` и `focus` — только там, где всё остальное и правда должно уйти в тень.
- `guess` и `answer` — неверная догадка крупно и её зачёркивание. Подходят, когда история опровергает догадку; без них ролик тоже собирается.
- Персонажи меняют лицо и позу (`states`), цвет (`roles`), значок (`badges`), ловят и вздрагивают. Так видно, что с героем случилось.
- Карточка кода внизу — настоящая строка как улика; в кадрах вместо неё `panel` со строками.
- Длина — от конца последней фразы. Обычно ролик держит внимание 20–40 секунд.
- В одном ролике один стиль. Как выбрать стиль и стилистику — `docs/styles/pixel.md` и `go run ./cmd/maket styles`.

Зоны кадра 1080×1920, общие для всех кадров:
- y 112…136 — полоса прогресса; выше 140 ничего своего не ставят.
- y около 1650…1800 — субтитр фразы. Подписи и статусы стоят на 40–70 px ниже ног, поэтому ноги ставят не ниже ~1520.
- Правые 140 px по x на платформах закрыты кнопками: важное туда не ставят, края кадра оставляют фону и обрезанным фигурам.
